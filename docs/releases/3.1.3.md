# JetVenta 3.1.3 - Lectura automática en listas de compra

- El código de barras se procesa automáticamente al terminar la lectura, sin depender de Enter.
- Enter y Return permanecen bloqueados en el campo del lector para evitar acciones de la ventana.
- `Guardar orden` se define explícitamente como una acción no predeterminada y sólo se ejecuta al pulsar su botón.
