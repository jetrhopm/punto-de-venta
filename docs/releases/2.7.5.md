# JetVenta 2.7.5 - Mayoreo manual por ticket

## F11

- F11 activa una excepción de mayoreo para el ticket actual, sin modificar mínimos ni precios del catálogo.
- Antes de activarla, JetVenta explica que aplicará mayoreo sin cumplir la cantidad mínima y pide confirmación.
- Sólo se aplica a partidas con precio de mayoreo configurado.
- Cada partida indica si usa menudeo, mayoreo por cantidad o mayoreo manual.
- F11 nuevamente retira la excepción y devuelve las reglas normales por cantidad.

## Seguridad

- Requiere el permiso `Aplicar precio de mayoreo manual (F11)` o una autorización temporal de una cuenta que lo tenga.
- La API vuelve a validar la autorización al cobrar; no acepta un precio manual enviado sin permiso.
- La autorización temporal se elimina al retirar la excepción, descartar el ticket o confirmarlo.
