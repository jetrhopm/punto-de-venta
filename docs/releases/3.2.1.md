# JetVenta 3.2.1 - Selección múltiple en listas de compra

## Corrección

La tabla de artículos de Listas y órdenes de compra permitía seleccionar filas, pero estaba configurada globalmente como de sólo lectura. Eso impedía activar las casillas y dejaba `Agregar selección` sin partidas que procesar.

Ahora se puede agregar a la lista de compra de cualquiera de estas formas:

- Marcar una o varias casillas.
- Seleccionar varias filas con `Ctrl` o `Shift`.
- Combinar ambas formas sin duplicar un artículo.

Las columnas informativas continúan siendo de sólo lectura. La corrección no modifica los cálculos de cantidades, existencias, órdenes ni el lector de código de barras.
