# JetVenta 3.2.7 - Alertas de configuración de impresora

## Corrección

La pantalla Configuración > Impresora ahora usa alertas globales adaptables para sus acciones:

- Actualizar impresoras informa si Windows detectó dispositivos o si no encontró ninguno.
- Probar impresión confirma el envío, explica si la impresión está desactivada y muestra los errores de impresión.
- Validar impresora y tamaño de fuente muestra mensajes visibles.
- Guardar configuración usa la confirmación global de configuración y cierra el formulario cuando la configuración queda guardada.

La carga inicial sigue siendo silenciosa y el estado inferior conserva un resumen de la última acción.
