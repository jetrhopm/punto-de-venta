# JetVenta 3.3.8 - Corrección de instalación inicial

## Corregido

- La configuración inicial de una instalación nueva ya no intenta volver a
  crear departamentos predeterminados que las migraciones hubieran insertado.
  Esto evitaba una violación de unicidad y el mensaje genérico de conexión al
  guardar los datos de tienda, giro, administrador y contraseña.
- El botón **Reparar servicios** del inicio identifica primero una instalación
  de servidor y ejecuta el script `install-production.ps1` de esa instalación
  con elevación. De esta forma no cae por error en el flujo de desarrollo ni
  queda sin abrir el reparador.

## Verificación recomendada

1. En una instalación limpia de servidor, completa el asistente inicial y
   guarda tienda, giro, usuario, contraseña y nombre de caja.
2. Confirma que aparece el inicio de sesión y que puedes entrar con el usuario
   creado.
3. Detén el servicio de API desde Windows y, en la pantalla inicial, pulsa
   **Reparar servicios**. Acepta la elevación y confirma que la API vuelve a
   responder.
