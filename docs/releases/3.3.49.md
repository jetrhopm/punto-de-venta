# JetVenta 3.3.49 - Reanudar cobros Point pendientes

## Corrección

Si una ventana Point se cerró tras una interrupción de red, el siguiente intento del mismo ticket y mismo importe retoma la orden pendiente existente. JetVenta conserva el identificador de esa orden y continúa consultando a Mercado Pago en vez de crear un segundo cargo o bloquear el ticket sin salida.

## Reglas de seguridad

- Sólo se retoma una orden de la misma caja, ticket e importe exacto.
- Si el ticket cambió de importe, JetVenta bloquea el nuevo cobro hasta resolver la orden anterior.
- Cuando Mercado Pago confirme rechazo, cancelación o vencimiento, el usuario podrá iniciar otro intento normal.
- No se crean cobros duplicados: la orden Point pendiente sigue siendo la única fuente de verdad.

## Prueba manual

1. Iniciar un cobro Point y simular una caída de red durante la consulta.
2. Cerrar el aviso y volver a cobrar el mismo ticket sin modificar el importe.
3. Confirmar que JetVenta muestra que retomó el cobro y consulta la misma orden en la terminal.
4. Probar cambiar el importe: debe bloquear con explicación hasta cancelar, expirar o resolver el cobro anterior.
