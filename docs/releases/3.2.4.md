# JetVenta 3.2.4 - Alertas de impresión y cierre de órdenes

## Correcciones visuales

- Al intentar imprimir una lista u orden sin impresora habilitada, JetVenta ahora muestra una alerta visible y explica que debe configurarse en `Configuración > Impresora`.
- El cierre de una orden muestra una confirmación visible al completarse.
- También se informa visualmente cuando no hay una orden seleccionada, la orden ya estaba cerrada o la API no pudo completar el cierre.

Estas alertas no modifican el estado de las órdenes ni inventario, costos, precios o ventas.
