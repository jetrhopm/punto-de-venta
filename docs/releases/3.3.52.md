# JetVenta 3.3.52 - Mensajes Point y cambio de importe pendiente

## Correcciones

- La ventana Point ahora interpreta la respuesta JSON de la API. Muestra correctamente mensajes con acentos y entiende respuestas normales, problemas y validaciones sin presentar JSON técnico.
- Si existe una creación Point pendiente y el ticket cambió de importe, JetVenta explica el siguiente paso seguro: restaurar el importe original y pulsar cobrar para reconciliar la misma operación.
- La operación pendiente no se puede cancelar ni sustituir mientras Mercado Pago no confirme si la recibió; así se evita duplicar un cargo real.
