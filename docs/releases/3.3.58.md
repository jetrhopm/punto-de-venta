# JetVenta 3.3.58 - Imprimir o no el corte de caja

## Novedades

- En **Configuración > Opciones habilitadas** hay una nueva opción: **"Imprimir el comprobante del corte de caja al cerrar turno"**.
  - **Si la caja tiene impresora:** la opción está habilitada y puedes marcarla o desmarcarla. Desmarcada, el turno se cierra y el corte se registra igual, pero no se imprime el ticket del corte.
  - **Si la caja no tiene impresora:** la opción aparece desactivada y sin marcar, con un aviso para configurar la impresora en Configuración > Impresora.
- Al cerrar turno, el mensaje de estado indica si el corte se imprimió, si la impresión está desactivada en Opciones habilitadas o si no hay impresora.

## Notas técnicas (para quien continúe el desarrollo)

- La preferencia es **por caja**, no por tienda, porque depende de la impresora configurada en cada equipo. Se guarda junto con la impresora en `machine-settings.json` (`%ProgramData%\PuntoDeVenta\client\`), así que **no requiere migración de base de datos** ni cambios en la API.
  - `ApiClient.PrintShiftCloseTicket` es la propiedad y `ApiClient.SetPrintShiftCloseTicket(bool)` guarda el valor.
  - `ClientSettings` tiene un nuevo campo opcional, `bool? PrintShiftCloseTicket = null`. Las configuraciones anteriores no lo tienen y lo leen como `true`, así que se conserva el comportamiento previo: imprimir.
- `StoreOptionsWindow`:
  - `LoadShiftClosePrinting()` habilita la casilla sólo si `ApiClient.IsTicketPrintingAvailable`.
  - La preferencia se guarda localmente después de que la API acepte el resto de las opciones, y sólo si hay impresora. Sin impresora, el valor guardado no se toca.
- `MainWindow`, al cerrar turno: `PrintShiftClose` sólo se llama si hay corte, hay impresora y `PrintShiftCloseTicket` está activo. Es el único lugar donde se imprime el comprobante de corte.

## Verificación pendiente

- Con impresora: desmarcar la opción, guardar, cerrar turno y confirmar que no se imprime y que el corte sí queda registrado. Volver a marcarla y confirmar que se imprime.
- Sin impresora: la casilla aparece desactivada y el aviso apunta a Configuración > Impresora.
