# JetVenta 3.3.48 - Consulta y verificación segura de Point

## Correcciones

- Las consultas de órdenes Point pendientes y reembolsos pendientes ahora usan condiciones que EF Core traduce correctamente a PostgreSQL. Se elimina el uso de métodos C# locales dentro de filtros SQL.
- Una orden Point `processed` sin `paid_amount` ya no se clasifica como importe distinto. Se mantiene como `PendingVerification`, bloqueada para venta, y JetVenta vuelve a consultar la orden hasta recibir el monto efectivo.
- `AmountMismatch` sólo se asigna cuando Mercado Pago informó un monto y éste es diferente al solicitado.

## Garantía de seguridad

JetVenta nunca finaliza una venta Point mientras falte la confirmación del importe efectivo. Esta corrección elimina falsos bloqueos por respuestas incompletas sin convertirlos en cobros aceptados.

## Pendiente de decisión

Las devoluciones entre cajas siguen bloqueadas por diseño: la venta pertenece a su caja original. Para permitirlas se requiere definir el permiso de autorización y la caja/turno que entrega efectivo antes de modificar ese flujo.
