# JetVenta 3.3.11 - Guía de conexión multicaja

## Implementado

- El instalador de **Caja adicional** muestra un acceso a instrucciones claras
  para preparar la red privada antes de emparejar el equipo.
- Desde `Configuración > Conectar caja` en la caja principal, el administrador
  puede ver y copiar una IP LAN privada real, generar el código temporal y
  seguir los pasos de instalación de la segunda caja.
- La guía explica el perfil de red **Privada** de Windows, la conexión al mismo
  router o switch, la recomendación de evitar suspensión en el servidor y el
  uso del puerto 5000 sin exponer el sistema a Internet.
- Se aclara expresamente que no se usa `127.0.0.1` en la segunda computadora,
  no se comparten carpetas, no se abre PostgreSQL y no se desactiva Firewall.
- Una caja adicional no puede generar códigos para agregar otras cajas desde su
  botón rápido; esa administración permanece en la caja principal.

## No modificado

El emparejamiento, las sesiones por caja, ventas, inventario concurrente,
servicios de servidor y reglas LAN existentes no cambiaron.
