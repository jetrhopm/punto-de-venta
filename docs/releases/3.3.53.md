# JetVenta 3.3.53 - Validaciones Point legibles

## Correcciones

- Las respuestas de validación priorizan ahora el mensaje específico de `errors` antes del título genérico de ASP.NET. El cajero verá el texto real en español, no “One or more validation errors occurred.”
- La consulta de una orden Point devuelve conflicto controlado para problemas de autorización, credenciales o caja incorrecta.
- La ventana de cobro interpreta ese conflicto y muestra el motivo real en vez de reintentarlo como si fuera una caída temporal de red.
