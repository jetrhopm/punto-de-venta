# JetVenta 3.0.0 - Planificación de compras

## Implementado

- Nuevo módulo **Planificar compras** disponible desde Compras.
- Sugerencias de reabasto para productos activos con existencia igual o menor al mínimo configurado.
- Filtros opcionales por proveedor y departamento.
- Los artículos sin proveedor siguen apareciendo y pueden agregarse a una orden sin proveedor asignado.
- Selección de varias sugerencias, orden con notas, partidas, cantidades sugeridas, costo estimado y total estimado.
- Consulta de órdenes pendientes y cerradas; el cierre sólo cambia el estado documental de la orden.

## Protección del flujo operativo

- Las órdenes no crean movimientos de inventario ni cambian existencia, costo, precio de venta o ventas.
- **Recibir compra** conserva su función actual y es el único flujo que registra mercancía y aumenta inventario.
- El módulo usa el permiso existente `Administrar compras y proveedores`.
