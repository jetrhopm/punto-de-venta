# JetVenta 3.3.47 - Reembolsos seguros de Mercado Pago Point

## Alcance

Esta versión incorpora reembolsos totales y parciales para órdenes Point cobradas con tarjeta. La operación se solicita a `POST /v1/orders/{order_id}/refund` con una clave de idempotencia propia y queda registrada antes de que JetVenta modifique la venta, el efectivo o el inventario.

## Comportamiento

- Una cancelación solicita el reembolso Point completo antes de cancelar localmente la venta.
- Una devolución parcial calcula primero la parte que corresponde al efectivo y solicita a Point sólo el importe pendiente de tarjeta.
- La devolución se calcula sobre el importe final realmente cobrado en la partida, incluidos descuentos y promociones; el último fragmento conserva los centavos restantes exactos.
- Si Mercado Pago confirma el reembolso, JetVenta continúa con la devolución o cancelación normal.
- Si Point queda procesando, hay una falla de red o el proveedor rechaza el reembolso, JetVenta no altera existencias, caja ni estado de la venta. El mismo intento puede repetirse de forma idempotente.
- Se conserva un historial técnico con importe, estado, identificador del proveedor, operación y fechas.
- Se habilita la segunda devolución parcial de una venta, sin exceder la cantidad vendida.

## Límites deliberados

- Una venta que combine Point con transferencia, crédito u otra tarjeta manual no se reembolsa automáticamente; se bloquea con explicación para evitar devolver un importe equivocado.
- Los reembolsos quedan sujetos a la elegibilidad de Mercado Pago: pago con tarjeta, orden procesada y un máximo de 90 días. La configuración de OAuth y Webhook central sigue pendiente antes de habilitar producción.
- Esta versión no modifica la regla histórica de cálculo de importe por línea ni la reversión de inventario de kits; son correcciones independientes ya identificadas.

## Pruebas requeridas

1. Con credenciales de prueba, cobrar una venta Point y cancelar: confirmar reembolso en Mercado Pago y después inventario, movimiento de efectivo y estado cancelado en JetVenta.
2. Cobrar una venta Point, devolver una parte y verificar que sólo se reembolsa esa cantidad.
3. Repetir la solicitud con la misma operación tras simular una interrupción: no debe aparecer un segundo reembolso.
4. Probar una devolución con efectivo + Point: el efectivo se cubre primero y Point recibe sólo el resto.
5. Probar una venta con Point más otra forma no compatible: JetVenta debe bloquear y explicar que requiere revisión manual.
