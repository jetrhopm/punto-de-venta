# JetVenta 3.3.51 - Creación Point tolerante a timeout

## Corrección de dinero real

Cuando una solicitud para crear una orden Point termina por timeout, interrupción de red o error temporal de Mercado Pago, JetVenta ya no la marca como fallida ni permite iniciar otra operación independiente.

- Conserva la orden como `CreationPending`.
- Al pulsar cobrar de nuevo para el mismo ticket e importe, reintenta usando el identificador original como llave de idempotencia.
- Si Mercado Pago creó la primera orden, devuelve esa misma orden en vez de enviarla otra vez a la terminal.
- Una orden cuya creación no se confirmó no puede cancelarse localmente: primero debe reintentarse y conciliarse.
- Los errores definitivos de Mercado Pago continúan marcándose como `CreationFailed`, permitiendo un nuevo intento.

## Prueba manual

1. Iniciar un cobro Point y cortar la red justo después de enviarlo.
2. Confirmar que JetVenta explica que conservará el intento.
3. Restaurar red y pulsar cobrar nuevamente sin cambiar el ticket.
4. Confirmar que se retoma la misma orden Point y que no aparece un segundo cobro en la terminal.
