# JetVenta 3.3.20 - Alcance visible de configuración

## Cambio

Todas las ventanas abiertas desde `Configuración` muestran ahora una etiqueta
visible y el mismo alcance en el título de la ventana:

- **Afecta a todas las cajas** para datos de tienda, usuarios, catálogo,
  políticas, importación y contenido comercial del ticket.
- **Sólo esta caja: nombre** para formas de pago, impresora, lector, cajón,
  báscula, inicio automático y datos locales de diagnóstico.
- Ambas leyendas en las pantallas mixtas: Ticket y Mercado Pago Point.
- **Sólo servidor** para cajas/equipos, emparejamiento, respaldos,
  facturación, licencia y diagnóstico del servidor.

El nombre se consulta desde la sesión y el registro de caja activo; no queda
fijo en la pantalla ni depende del usuario de Windows.

## Prueba manual

1. Inicia sesión en Caja 1 y abre `Configuración > Formas de pago`.
2. Confirma que aparece `Sólo esta caja: Caja 1` tanto en la etiqueta como en
   el título.
3. Abre `Datos de la tienda`, `Corte` y `Símbolo de moneda`; deben mostrar
   `Afecta a todas las cajas`.
4. Abre `Ticket` y `Mercado Pago Point`; deben explicar ambos alcances.
5. En una caja adicional, abre Impresora, Lector, Cajón y Báscula; cada una
   debe indicar el nombre de esa caja.
6. En el servidor, abre Respaldos o Cajas y equipos; deben indicar
   `Sólo servidor`.
