# JetVenta 2.5.5

## Reportes

- Se agrega la pestaña `Gráficas de pastel`.
- Se muestra la distribución de cobros por forma de pago.
- Se muestra la distribución de ventas por departamento.
- Las gráficas usan un estilo de dona, leyendas con porcentaje e importes, y colores consistentes con JetVenta.
- Se corrige el caso de una sola categoría para que se renderice como círculo completo.
- Cuando el periodo no tiene ventas o los datos llegan vacíos, se muestran estados informativos y no se intenta calcular máximos sobre una colección nula o vacía.

## Alcance

Este cambio es visual y de presentación. No modifica los endpoints, filtros, consultas ni cálculos existentes de Reportes. Las gráficas nuevas transforman los mismos datos que ya utiliza el resumen visual.

## Pruebas de aceptación

1. Abrir `Reportes` y consultar `Semana actual`, `Mes actual` o un periodo personalizado con ventas.
2. Abrir `Gráficas de pastel` y confirmar que aparecen las gráficas de formas de pago y departamentos cuando hay información.
3. Confirmar que cada leyenda muestra color, nombre, porcentaje e importe.
4. Comparar los importes de las gráficas con las barras del `Resumen visual`; deben coincidir.
5. Consultar un periodo sin ventas, por ejemplo un rango de fechas anterior a la instalación. La vista debe mostrar el mensaje de datos no disponibles, sin excepción ni ventana técnica.
6. Probar un periodo con una sola forma de pago o un solo departamento. Debe mostrarse una dona completa y su leyenda.
7. Cambiar entre pestañas y periodos varias veces. No deben quedar datos visuales del periodo anterior.
