# JetVenta 2.5.10 - Departamentos y alcance controlado

## Alcance aplicado

Esta versión sigue las notas verificadas y no cambia el sistema general de permisos.

- El alta y la edición manual de departamentos bloquean duplicados que sólo difieren por mayúsculas, minúsculas o acentos.
- La comprobación también reconoce datos antiguos que pudieran haber sido guardados antes de esta normalización.
- Se verificó que la autorización temporal muestra credenciales inválidas y permiso insuficiente sin modificar sus reglas.
- Se verificó que producto común usa el permiso `UseCommonProduct`, se registra como temporal y se agrega directamente al ticket del flujo de producto no encontrado.
- Se verificó que Clientes y Créditos permanecen en módulos separados, con edición y baja lógica de clientes.

## Pruebas

1. Crear `Lácteos` y tratar de crear o renombrar otro departamento como `LACTEOS`: debe impedirse el duplicado.
2. Producto no encontrado: elegir `Producto común (temporal)` y confirmar que se agrega al ticket sin modificar inventario.
3. Solicitar autorización temporal con contraseña incorrecta y con una cuenta sin el permiso: deben mostrarse avisos claros.
4. Crear, editar y desactivar un cliente; revisar que Créditos conserva su historial.

## Control de cambios

- A partir de esta versión sólo se modificarán hallazgos documentados.
- Si una corrección requiere alterar un flujo fuera de las notas, se explicará el motivo y se solicitará aprobación antes de hacerlo.

## Retorno seguro

- Base anterior: `v2.5.9`.
- Puntos conservados: desde `v2.5.5` hasta `v2.5.9`.
