# JetVenta 2.3.8

## Alcance

Esta versión mejora el flujo temporal de caja única. No habilita multicaja ni permite compartir un turno entre usuarios.

## Cambios

- Cuando una cuenta intenta abrir una caja que ya tiene turno abierto, la API identifica de forma segura al usuario responsable y la fecha de apertura.
- JetVenta muestra una alerta clara en vez de un conflicto genérico.
- La alerta explica que se debe cerrar la sesión actual e iniciar con la cuenta indicada para realizar el corte antes de que otro cajero opere.
- La regla de un turno abierto por caja se conserva, incluso si dos solicitudes de apertura se realizan casi al mismo tiempo.

## Prueba

1. Inicia sesión como administrador y abre caja sin cerrar turno.
2. Cierra JetVenta sin realizar corte.
3. Inicia con un cajero distinto e intenta abrir caja.
4. Confirma que aparece el nombre del administrador y la hora del turno abierto.
5. Cierra la sesión, entra como administrador, realiza corte y verifica que el cajero ya puede abrir caja.
