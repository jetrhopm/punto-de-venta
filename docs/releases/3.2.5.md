# JetVenta 3.2.5 - Alertas adaptables

## Corrección global

Las tres plantillas de notificación de JetVenta ahora ajustan su altura al contenido:

- Resultados con `Aceptar`.
- Confirmaciones con `Cancelar` y `Confirmar`.
- Confirmaciones al guardar configuración.

El texto ordinario expande el diálogo automáticamente. Para diagnósticos inusualmente extensos, el área de mensaje conserva el diseño y activa desplazamiento vertical, evitando que el texto o los botones queden fuera de la pantalla.

La mejora se aplica tanto a las alertas que usan `OperationResultWindow` directamente como a las llamadas `MessageBox.Show(...)`, que JetVenta redirige a estas plantillas.
