# JetVenta 2.5.32 - Botón de bajas en Productos F3

## Cambio visual

`Mostrar bajas` en Productos F3 dejó de ser una casilla. Ahora es un botón del grupo Bajas lógicas que alterna a `Ocultar bajas` y queda rojo mientras el catálogo incluye productos retirados.

El filtro y la lógica de baja o reactivación no cambiaron.
