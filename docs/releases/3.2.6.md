# JetVenta 3.2.6 - Alertas de configuración del lector

## Corrección

La pantalla Configuración > Lector de códigos ya no depende sólo del texto de estado inferior para informar resultados.

- Actualizar puertos muestra si Windows detectó puertos COM o explica qué revisar si no encuentra ninguno.
- Probar puerto informa el resultado para modos teclado y serial, incluido el detalle de un error al abrir el puerto.
- Guardar configuración usa la confirmación global de configuración y cierra el formulario al guardar correctamente, como las demás opciones de Configuración.

El texto inferior permanece como resumen del último estado, pero las acciones importantes ahora tienen alerta visible y adaptable.
