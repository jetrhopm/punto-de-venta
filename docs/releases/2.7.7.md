# JetVenta 2.7.7 - Mayoreo manual por partida

## F11

- F11 ahora opera únicamente sobre la partida seleccionada en el ticket.
- Sólo la fila seleccionada recibe el precio de mayoreo manual; las demás no cambian.
- La confirmación muestra el mínimo y unidad de mayoreo del artículo seleccionado.
- Al quitar la excepción, sólo se restaura la regla normal de esa partida.

## Retorno seguro

- Base anterior: `v2.7.6`.
- Se mantienen los tags desde `v2.5.5` hasta `v2.7.6`.
