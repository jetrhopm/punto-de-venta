# JetVenta 3.3.12 - Configuración de pagos compartida

## Corrección

- Las formas de pago se conservan como configuración global de la tienda.
- Cualquier usuario con sesión vigente puede leerlas al abrir el cobro, por lo
  que un cajero verá las mismas opciones activas que configuró el administrador.
- La edición continúa restringida a administradores o a usuarios con el permiso
  `Configurar tienda`; un cajero no puede modificar la configuración.

## Verificación

1. Como administrador, activa o desactiva métodos en `Configuración > Formas de pago`.
2. Inicia sesión con un cajero y abre `Cobrar`: deben aparecer exactamente los
   métodos configurados.
3. Confirma que el cajero no obtiene acceso para guardar cambios de configuración.
