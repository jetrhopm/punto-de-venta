# JetVenta 3.1.1 - Lista de compra consolidada

## Diseño y operación

- El lector y el campo de código se trasladaron encima de la tabla original de sugerencias; no se abre ni se muestra una segunda lista de búsqueda.
- La ventana de Planificar compras se amplió para ver sugerencias y lista de compra sin comprimir las columnas.
- La tabla de sugerencias conserva sus checks, el botón `Agregar selección` y el doble clic para agregar artículos.
- La lista de compra ahora muestra código, producto, cantidad, costo e importe. La cantidad puede editarse directamente antes de guardar o imprimir.

## Cálculo sugerido

- Cuando el artículo está bajo su mínimo y tiene máximo configurado, se propone completar hasta el máximo.
- Ejemplo: existencia `23`, máximo `100`, cantidad inicial de compra `77`.
- Sin máximo configurado, se conserva la reposición mínima existente.
- Una nueva lectura del mismo código suma una unidad a la línea existente; no duplica el artículo.

## Seguridad

- La planeación, edición de cantidades e impresión no modifican inventario, costos, precios, ventas ni movimientos.

## Pruebas

1. Leer un código exacto con teclado o escáner y comprobar que se agrega a la lista de compra.
2. Dar doble clic a una sugerencia y comprobar que se agrega sin alerta.
3. Marcar varios checks y usar `Agregar selección`.
4. Cambiar una cantidad en la lista y confirmar que actualiza importe y total estimado.
5. Usar un artículo con existencia `23` y máximo `100` y confirmar una sugerencia de `77`.
6. Imprimir la lista y confirmar que no modifica existencias.
