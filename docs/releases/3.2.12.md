# JetVenta 3.2.12 - Una instancia por equipo

## Corrección

El cliente de escritorio ahora usa un mutex global de Windows para permitir
una sola instancia de JetVenta por computadora a la vez.

- La primera ejecución conserva la instancia activa.
- Un segundo intento muestra `JetVenta ya está abierto` y termina antes de
  crear otra ventana, sesión o flujo de ventas.
- La API continúa siendo un proceso independiente; esta restricción sólo
  corresponde al cliente de escritorio.
- El control no depende del nombre actual `Pos.Desktop.exe`, por lo que se
  mantendrá al renombrar el ejecutable a `JetVenta.exe` en una versión futura.

## Prueba manual

1. Abre JetVenta e inicia sesión normalmente.
2. Sin cerrar la primera ventana, ejecuta otra vez `Pos.Desktop.exe`.
3. Debe aparecer el aviso `JetVenta ya está abierto`.
4. Al aceptar, sólo debe permanecer la primera ventana; no debe crearse una
   segunda sesión, ticket ni conexión de escritorio.
