# JetVenta 3.3.31 - Selección inmediata en promociones

## Corrección

- Cuando un lector USB escribe un código y envía Enter en el selector de producto de Promociones, JetVenta consulta el código de inmediato y selecciona el artículo exacto.
- La búsqueda asíncrona con lista se conserva para coincidencias parciales.
