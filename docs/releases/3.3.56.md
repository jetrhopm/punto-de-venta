# JetVenta 3.3.56

- Permite consultar el código de solicitud y activar una licencia vencida desde el inicio de sesión, con credenciales de administrador, sin requerir abrir un turno.
- Registra el pago a proveedor desde efectivo de caja como una salida que se refleja en el corte del turno.
- Incluye los ajustes recientes de turnos, inventario y periféricos que permanecían sin incremento de versión.
