# JetVenta 3.3.23

## Instalación de caja adicional

- El instalador ahora aclara que el nombre de caja es editable y muestra ejemplos como `Caja 2` y `Caja mostrador`.
- Si se intenta instalar o actualizar sin aceptar los términos, muestra una alerta visible y dirige al control correspondiente.

## Emparejamiento desde la caja principal

- La ventana de conexión muestra explícitamente el puerto de JetVenta: `5000`, junto con la IP y el código temporal.
- No se modificó el flujo de emparejamiento, la red LAN ni las sesiones de caja.
