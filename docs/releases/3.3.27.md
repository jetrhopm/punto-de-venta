# JetVenta 3.3.27 - Configuración inicial en instalación limpia

## Corrección crítica

- Se agrega la migración que faltaba para la configuración de formas de pago por caja.
- En una base de datos nueva, la primera caja ahora incluye efectivo, tarjeta, transferencia, crédito y la disponibilidad local de Mercado Pago desde su creación.
- La migración usa `IF NOT EXISTS`, por lo que es segura al actualizar instalaciones existentes: no elimina datos ni falla si una columna ya existe.

## Causa corregida

La pantalla de configuración inicial creaba la primera caja con las formas de pago locales, pero la estructura de una base de datos nueva no incluía aún esas columnas. La API respondía como indisponible, aunque la causa real era el error de estructura de base de datos.

## Prueba obligatoria

1. Instalar como `Caja principal / servidor` en una computadora limpia.
2. Abrir JetVenta y completar tienda, giro, administrador y primera caja.
3. Confirmar que `Crear tienda` termina correctamente y muestra el inicio de sesión.
4. Entrar a Configuración > Formas de pago de esta caja y confirmar que se muestran los métodos predeterminados.
