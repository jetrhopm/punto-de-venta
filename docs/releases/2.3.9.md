# JetVenta 2.3.9

## Alcance

Mejora puntual para el aviso de caja única de la versión 2.3.8. No modifica turnos, corte, ventas ni permisos.

## Cambios

- La alerta de turno abierto incluye **Cambiar usuario** y **Cancelar**.
- **Cambiar usuario** cierra sólo la sesión actual y abre el inicio de sesión para elegir la cuenta que dejó el turno abierto.
- **Cancelar** sólo oculta la alerta; no cierra turno, no realiza corte, no elimina tickets y no cierra el programa.

## Prueba

1. Deja un turno abierto con un usuario A e inicia con usuario B.
2. Intenta abrir caja y confirma que aparece el aviso de turno abierto.
3. Pulsa Cancelar: verifica que el aviso se oculta y el turno de A sigue intacto.
4. Repite y pulsa Cambiar usuario: debe volver al login sin cerrar el turno de A.
