# JetVenta 2.3.3

## Alcance

Esta version corrige el bloque de acceso, demo, licencia, autorizaciones temporales y comunicacion visible de recuperacion de API. No modifica la creacion de tickets, las lineas de venta, cobros, turnos, inventario ni respaldos.

## Cambios

- El login asigna explicitamente el usuario elegido y filtra usuarios activos mientras se escribe.
- Antes de iniciar sesion se muestra el estado limitado de demo o licencia sin exponer codigo de solicitud, huella del equipo ni datos de licencia.
- El boton Activar licencia exige usuario y contraseña validos y abre la ventana de activacion despues de autenticar la sesion.
- Una demo vencida se muestra desde el login y orienta al usuario a activar la licencia.
- El recordatorio de demo persiste al abrir la pantalla de ventas.
- La autorizacion temporal responde y muestra por separado: sesion no valida, usuario o contraseña incorrectos, y cuenta sin permiso requerido.
- El arranque confirma visualmente cuando una API local fue recuperada antes de continuar al login.

## Riesgos y regresion

El cambio toca autenticacion y ventanas de inicio. Antes de aprobar esta version deben verificarse:

1. Abrir JetVenta con la API activa y llegar al login.
2. Elegir un usuario de la lista, escribir contraseña y entrar.
3. Intentar login con usuario vacio, usuario inexistente y contraseña incorrecta.
4. Crear ticket con F6, agregar producto, cobrar una venta de prueba y confirmar historial.
5. Intentar una accion restringida con contraseña incorrecta y con una cuenta sin permiso.
6. Confirmar que una cuenta administradora puede autorizar temporalmente una accion y que el permiso no queda permanente.

## Criterios de aceptacion

- Elegir una cuenta llena el campo Usuario con su nombre de usuario real.
- La demo muestra tiempo restante al abrir mientras no exista una licencia activa.
- Activar licencia no permite saltar el login ni exponer informacion sensible.
- Cada rechazo de autorizacion informa una causa accionable.
- La recuperacion de API informa exito antes de abrir el login.
- La regresion de tickets y ventas sigue funcionando.
