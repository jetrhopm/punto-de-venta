# JetVenta 2.5.6

## Alcance

Esta version corrige exclusivamente la continuidad del periodo de prueba despues de desinstalar y reinstalar JetVenta. No modifica ventas, tickets, caja, inventario, permisos ni la firma de los archivos `licencia.jv`.

## Correccion

- La demo mantiene dos copias cifradas y vinculadas al equipo: una en `C:\ProgramData\PuntoDeVenta\license\demo.jv.dpapi` y otra protegida en el registro local de Windows.
- Al actualizar desde una version anterior, la copia existente se conserva y se replica al segundo almacenamiento al consultar el estado de licencia.
- Si una copia falta despues de una desinstalacion normal, JetVenta recupera la informacion desde la otra sin comenzar otros 30 dias.
- Si ambas copias existen con tiempos distintos, se conserva el inicio mas antiguo y la ultima hora observada mas reciente.
- La desinstalacion normal retira el archivo de licencia activa y su reloj de vigencia, pero conserva la evidencia de demo para el mismo equipo.
- El archivo `licencia.jv` firmado se puede volver a cargar en el mismo equipo despues de reinstalarlo. No se cambia el codigo de activacion ni se incorpora la fecha de instalacion a la huella.

## Limite conocido

Un administrador con control total puede borrar deliberadamente tanto los datos de programa como el registro de Windows, o reinstalar el sistema operativo. Una proteccion exclusivamente local no puede demostrar el uso anterior en ese caso. La validacion hibrida quedara para una fase posterior.

## Pruebas de aceptacion

1. Iniciar JetVenta sin licencia, anotar el tiempo restante, desinstalar y reinstalar. El tiempo debe continuar, no volver a 30 dias.
2. Actualizar una instalacion 2.5.5 con demo en curso. Debe conservar el mismo vencimiento.
3. Activar una licencia valida, desinstalar, reinstalar y confirmar que la licencia activa se retiro. Cargar el mismo archivo `.jv`; debe volver a activar solo ese equipo.
4. Cambiar la hora hacia atras y hacia adelante. Se conserva el comportamiento ya aprobado de bloqueo por reloj.
5. Limpiar o restaurar la base de datos. El estado de demo no debe cambiar.
