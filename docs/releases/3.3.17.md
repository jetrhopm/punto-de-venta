# JetVenta 3.3.17 - Formas de pago por caja

## Cambio

Las formas de pago ya no son una configuracion unica de toda la tienda. Cada
caja tiene su propio perfil de efectivo, tarjeta, transferencia y credito.

La migracion copia exactamente los valores que la tienda tenia antes hacia cada
caja existente. Por ello, actualizar no habilita ni deshabilita formas de pago
de manera inesperada.

Al cobrar, la API valida la caja de la sesion autenticada. Aunque alguien
intente alterar la pantalla, no puede cobrar con una forma de pago desactivada
para esa caja.

La ventana `Configuracion > Formas de pago` ahora indica que modifica solo la
caja actual.

## Prueba

1. En Caja 1, iniciar como administrador y abrir `Configuracion > Formas de pago`.
2. Desactivar tarjeta, guardar y confirmar que la ventana indica Caja 1.
3. Abrir cobro en Caja 1: tarjeta no debe aparecer.
4. En Caja 2, abrir cobro: tarjeta debe permanecer disponible.
5. Intentar enviar una venta con tarjeta desde Caja 1: la API debe rechazarla.
6. Confirmar que efectivo, transferencia y credito conservan el valor que
   tenian antes de actualizar en cada caja.
