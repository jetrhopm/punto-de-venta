# JetVenta 2.5.14

## Alcance

Correcciones puntuales derivadas de las pruebas de la revisión 2.5.5 a 2.5.13. Esta versión no modifica ventas, compras, ajustes manuales ni el flujo de departamentos.

## Reportes

- Las leyendas de las gráficas de pastel de formas de pago y departamentos muestran tanto el porcentaje como el importe real del periodo.
- Ejemplo: `80%  $1,000.00`.

## Importación de existencia

- La existencia indicada en cada fila importada se guarda como existencia final del producto, incluso cuando el control global de inventario esté deshabilitado.
- Con inventario habilitado, el cambio conserva su movimiento de inventario con existencia anterior, final y operación de importación.
- Con inventario deshabilitado, no se crea un movimiento operativo porque el control está apagado, pero la existencia queda lista para cuando se active.
- La importación continúa usando el valor de existencia del archivo como valor final, no como una entrada adicional.

## Pruebas de regresión

- Se agregó una prueba de integración que importa un artículo con inventario global deshabilitado y verifica que conserva su existencia sin crear movimiento de inventario.
- Se mantienen las pruebas existentes de actualización, idempotencia, departamentos y movimientos al importar con inventario habilitado.

## Punto de retorno

La versión se etiquetará como `v2.5.14` después de compilar y ejecutar las pruebas. Las etiquetas `v2.5.5` a `v2.5.13` no se alteran.
