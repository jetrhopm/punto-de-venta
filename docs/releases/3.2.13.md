# JetVenta 3.2.13 - Ejecutable con nombre comercial

## Cambio

El cliente de escritorio ahora se genera como `JetVenta.exe` en lugar de
`Pos.Desktop.exe`.

## Actualización compatible

El instalador conserva la compatibilidad con instalaciones anteriores:

- Detecta instalaciones que tengan `Pos.Desktop.exe` o `JetVenta.exe`.
- Solicita cerrar cualquiera de los dos procesos antes de actualizar.
- Reemplaza los accesos directos y el inicio automático de Windows para usar
  `JetVenta.exe`.
- Retira los archivos ejecutables y metadatos del cliente con el nombre
  anterior después de actualizar correctamente.

No cambia la base de datos, licencias, API, ventas ni la modalidad monocaja.
El control de una instancia única usa un mutex independiente del nombre del
archivo y se mantiene activo.

## Pruebas requeridas

1. Ejecutar `JetVenta.exe` desde la compilación o instalación nueva.
2. Verificar accesos directo de escritorio, menú Inicio e inicio automático.
3. Actualizar una instalación que todavía use `Pos.Desktop.exe` y confirmar
   que arranca `JetVenta.exe` sin dejar el ejecutable anterior.
4. Intentar abrir `JetVenta.exe` dos veces: sólo debe quedar la primera
   instancia.
