# JetVenta 3.3.57 - Etiquetas legibles por lector y versión numérica

## Correcciones

- Las etiquetas de producto (Ctrl+O) generan códigos de barras que el lector sí lee. Antes sólo algunos códigos cortos (por ejemplo "FRESA") se leían; los numéricos de 12 o 13 dígitos (EAN) no, ni en papel térmico ni en PDF.
- El código de barras de la etiqueta vuelve a imprimirse en horizontal y centrado. Sólo un código demasiado largo para el ancho del papel se imprime en vertical, para que nunca se corte.
- La versión del programa se muestra siempre como número (por ejemplo `3.3.57`). Ya no aparece un identificador alfanumérico (`3.3.56+e3193057...`) en las propiedades del ejecutable ni en Detalles del sistema.

## Notas técnicas (para quien continúe el desarrollo)

### Código de barras (`src/Pos.Desktop/TicketWindowsPrinter.cs`)

- **Causa raíz:** el módulo Code 128 medía `1.4` DIP y las barras tenían `UseLayoutRounding = true` y `SnapsToDevicePixels = true`. WPF redondeaba cada barra a píxeles enteros de 96 dpi, así que los anchos 1:2:3:4 salían como 1:3:(4-5):6. Se verificó midiendo los rectángulos de los PDF generados (todas las medidas eran múltiplos de 0.75 pt = 1 px) y con el algoritmo de decodificación de referencia de Code 128: FRESA tenía 6 de 8 símbolos fuera de tolerancia y 7501040070624 tenía 7 de 11. Que FRESA se leyera era tolerancia del lector, no un código correcto.
- `Code128Barcode.cs` **no** tenía error: la tabla de patrones es idéntica al estándar, y el checksum y el cambio de Code C a Code B para longitudes impares están bien. No hace falta tocarlo.
- **Corrección:**
  - Nueva constante `ThermalDotDips = 96 / 203` (un punto de una térmica de 203 dpi).
  - El módulo se cuantiza a puntos enteros. En vertical mide 3 puntos. En horizontal usa `floor(ancho / módulos / punto)` puntos, con un mínimo de 2.
  - `UseLayoutRounding` y `SnapsToDevicePixels` se fijan **explícitamente en `false`** en el `Canvas` y en cada barra. La propiedad se hereda, así que no basta con quitarla.
  - `CreateProductLabelsVisual` usa `CreateCode128Canvas`, que es horizontal y centrado, cuando `FitsHorizontalCode128` confirma que el código cabe con 2 puntos por módulo y 10 módulos de zona silenciosa por lado. Si no cabe, usa `CreateVerticalCode128Canvas`.
  - Referencias en 80 mm (ancho útil ~246 DIP): un EAN-13 sale con módulo de 3 puntos y FRESA con 4. En 58 mm, un EAN-13 sale con 2 puntos.
- **No volver a activar** el redondeo de layout en los códigos de barras.

### Versión

- En `Directory.Build.props` se subió a `3.3.57` y se agregó `IncludeSourceRevisionInInformationalVersion=false`. El SDK de .NET agregaba `+<sha de git>` a `InformationalVersion`, que es la "Versión del producto" que muestra Windows.
- `SystemDetailsWindow.xaml.cs` muestra `Version.ToString(3)`, igual que Login, Inicio y Diagnóstico. Antes mostraba 4 partes (`3.3.56.0`).
- **Convención:** cada cambio sube el último número de `Version`, `AssemblyVersion`, `FileVersion` e `InformationalVersion` en `Directory.Build.props`, y agrega `docs/releases/<versión>.md`.

### Revisión del flujo de Etiquetas (Ctrl+O) pendiente de corregir

Se revisó `ProductLabelWindow.xaml(.cs)` sin modificarlo. Hallazgos:

1. Con Etiquetas abierta y Ventas detrás, el lector serial también agrega el producto al carrito: `MainWindow.OnSerialBarcodeScanned` no ignora los escaneos mientras hay una ventana modal propia abierta. Lo mismo pasa en Compras y Planeación de compras.
2. Enter en la lista de resultados no elige el producto. El `DataGrid` consume Enter antes de `KeyDown`; hace falta `PreviewKeyDown`.
3. `SelectProduct` asigna `SearchBox.Text`, eso dispara otra búsqueda que recarga la lista y borra el mensaje "Etiqueta lista".
4. Si se escribe otro texto después de elegir un producto, `_selectedProduct` conserva el anterior y se imprime ese.
5. Enter con la búsqueda diferida (180 ms) aún pendiente puede tomar la fila seleccionada de la búsqueda anterior.
6. Enter en Cantidad no imprime.
7. Cada impresión exitosa abre un aviso modal, el foco no regresa a la búsqueda y no hay protección contra doble impresión.
