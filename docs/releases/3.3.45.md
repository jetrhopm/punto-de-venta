# JetVenta 3.3.45 - Colores de acciones administrativas

## Diseño

- Historial de ventas: Devolver es naranja, Cancelar es rojo e Imprimir es verde.
- Cajas y equipos, Diagnóstico, Licencia, Detalles del sistema y Datos del cliente ahora distinguen visualmente acciones de consulta, confirmación, advertencia y cierre.
- No se modificaron eventos, permisos, validaciones ni flujos de negocio.
