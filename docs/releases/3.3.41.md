# JetVenta 3.3.41 - Tamaño de letra desde impresora

## Mejora

- Configuración > Impresora permite ajustar el tamaño de letra de 6 a 24 puntos junto con el ancho y desplazamiento del ticket.
- El valor se guarda por computadora y se comparte con Configuración > Diseño de ticket.
- En impresoras de 58 mm se puede reducir ligeramente el tamaño para recuperar espacio del lado derecho sin desalinear el izquierdo.
