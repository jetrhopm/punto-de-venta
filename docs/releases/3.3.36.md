# JetVenta 3.3.36 - Mejora lector de barras en kits

## Corrección

- Mientras el foco esté en **Buscar artículo para agregar**, JetVenta ignora cualquier activación de **Guardar composición** provocada por el Enter final del lector.
- Guardar composición continúa disponible mediante clic o al enfocar el botón con Tab.
