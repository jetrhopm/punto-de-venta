# JetVenta 3.1.4 - Enter aislado para lector en compras

- Corregida la captura global de Enter que elegía `Guardar orden` antes de que el campo de código pudiera procesar una lectura.
- Sólo el campo de lector de `Planificar compras` queda excluido del comportamiento global de confirmación.
- Un código corto, por ejemplo `85`, con Enter se agrega a la lista cuando existe de forma exacta; no crea ni guarda una orden.
