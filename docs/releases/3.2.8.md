# JetVenta 3.2.8 - Alertas de configuración y mantenimiento

## Alcance

Esta versión unifica el resultado visible de operaciones de configuración y mantenimiento mediante el mismo diseño adaptable de alertas de JetVenta. La lógica de dispositivos, ventas, inventario y servicios no cambió.

## Pantallas actualizadas

- Cajón de dinero: guardar, validar impresora y probar apertura.
- Báscula: actualizar puertos COM, guardar, validar y probar lectura.
- Mercado Pago Point: token de prueba, autorización, terminales, activación, desconexión y modo PDV.
- Importar productos e inventario: archivo inválido, validación previa, respaldo preventivo, importación, errores y guardado de reporte.
- Detalles del sistema: actualizar el estado del servicio.
- Licencia: actualizar estado, copiar solicitud e importar licencia.
- Diagnóstico: actualizar, levantar API, limpiar historial técnico, descartar cola e informar la copia del reporte.
- Folio de venta: validaciones y guardado del consecutivo.
- Inicio automático: guardar la preferencia de Windows.
- Respaldos: crear y verificar una nueva copia.
- Cajeros y permisos: guardar datos/permisos y activar o desactivar cuentas.

Las respuestas de API se traducen mediante `ConfigurationFeedback` cuando es posible para evitar mostrar JSON técnico.

## Diseño y navegación

- Se agregó `OperationFeedback` como acceso común al cuadro global adaptable.
- El estado inferior de cada ventana se conserva como resumen de la última acción.
- La consulta inicial de una pantalla permanece silenciosa; las alertas aparecen al ejecutar una acción explícita.
- El acceso `Modificar folios` se movió al final de la sección General de Configuración.
- El icono de Inicio automático ahora usa una aplicación con engrane, en lugar del símbolo de encendido que se percibía como una barra.

## Pruebas de regresión

1. Abrir cada pantalla de la lista no debe mostrar una alerta durante su carga inicial.
2. Ejecutar una acción válida y una inválida en cada pantalla debe mostrar una alerta completa, con texto ajustable y botón Aceptar.
3. Guardar un respaldo debe actualizar la lista y mostrar `Respaldo creado`.
4. En Importar, un archivo inválido o una importación rechazada debe mostrar explicación legible, sin JSON técnico.
5. Las confirmaciones existentes conservan `Enter` y `Esc` según su diseño global.
