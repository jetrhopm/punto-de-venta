# JetVenta 3.1.2 - Enter del lector en lista de compra

- El campo de código de `Planificar compras` captura Enter antes de que pueda llegar a otra acción de la ventana.
- Enter y Return se reservan para buscar el código exacto y agregarlo a la lista de compra.
- Guardar una orden no se ejecuta con Enter; permanece como acción explícita del botón `Guardar orden`.
