# JetVenta 2.7.1 - Corrección de apertura de Kits

## Corrección

El diálogo de Kits ya no depende de estilos definidos únicamente dentro de Productos F3. Ahora incluye su estilo local y puede abrirse correctamente desde `Productos > Organización > Kits`.
