# JetVenta 2.5.26 - Cotización y referencia de promociones

## Corrección

- La cotización de promoción durante la venta requiere una sesión vigente, no el permiso de venta. Esto evita que la pantalla vuelva silenciosamente al precio normal antes de solicitar una autorización temporal.
- El cobro final continúa validando el permiso `Sell`; esta corrección no abre la venta a usuarios sin autorización.
- Se prueban explícitamente porcentaje, descuento fijo y compra N/paga M para impedir regresiones en las tres fórmulas.

## Interfaz

- Al elegir un producto se muestran costo y precio de venta.
- La lista de promociones muestra producto, costo y precio de venta.
- El tipo antes llamado `Importe fijo` se muestra como `Descuento fijo ($)`: el valor es el monto que se resta del precio de venta, no un precio final fijo.

## Pruebas manuales

1. Crea para un producto de $100 una promoción de 15% y agrega dos unidades a un ticket: deben totalizar $170.
2. Crea para un producto de $100 un descuento fijo de $12 y agrega dos unidades: deben totalizar $176.
3. Crea compra 3 y paga 2 para el mismo precio: tres unidades deben totalizar $200.
4. Confirma que el renglón de venta, el total de cobro y el ticket confirmado coinciden.
