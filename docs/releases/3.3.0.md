# JetVenta 3.3.0 - Base de configuración por computadora

## Objetivo

Iniciar multicaja sin alterar el flujo estable de ventas monocaja. Esta versión
define que una caja y sus periféricos pertenecen a la computadora Windows, no
al perfil de Windows ni al usuario de JetVenta.

## Implementado

- La conexión al servidor, identidad de caja emparejada, impresora y lector de
  código se guardan en `%ProgramData%\PuntoDeVenta\client\machine-settings.json`.
- La identidad de la caja se protege con DPAPI de máquina. Todos los usuarios
  que abran JetVenta en el mismo equipo usan la misma configuración local.
- La primera ejecución migra automáticamente el archivo anterior ubicado en
  `%LocalAppData%\PuntoDeVenta\client-settings.json`; nunca borra el original.
- Si el archivo antiguo fue creado por otro perfil de Windows y no puede
  descifrarse el token, conserva conexión y periféricos, pero elimina sólo la
  identidad de caja para solicitar un nuevo emparejamiento cuando sea necesario.
- La escritura del archivo común es atómica para no dejar una configuración
  incompleta ante un cierre inesperado.

## Alcance que aún no se activa

Las ventas, turnos, tickets, caja, inventario y autorización siguen en el
flujo monocaja estable. Las siguientes versiones enlazarán esas operaciones a
la caja emparejada antes de habilitar la venta desde una segunda computadora.

La configuración de cajón, báscula y terminal de pago se moverá a la caja
correspondiente cuando ya exista el contexto seguro de sesión por dispositivo.

## Punto de retorno

- Antes del cambio: `checkpoint-v3.2.13-antes-multicaja`.
- Esta versión: etiqueta `v3.3.0`.

## Pruebas requeridas

1. Configurar impresora y lector con un administrador de Windows y abrir
   JetVenta con otro perfil del mismo equipo: ambos deben ver la misma
   configuración.
2. Confirmar que una instalación monocaja existente conserva conexión y puede
   abrir ventas con normalidad después de migrar el archivo.
3. Confirmar que el archivo anterior permanece intacto como respaldo.
