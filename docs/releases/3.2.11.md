# JetVenta 3.2.11 - Bloqueo de crédito por cliente

## Función

Créditos F2 ahora permite congelar el crédito de un cliente mediante `Bloquear nuevas ventas a crédito`.

- El bloqueo no elimina el cliente, sus movimientos ni su saldo pendiente.
- El cliente bloqueado continúa apareciendo en Créditos F2 para consultar movimientos y registrar abonos.
- Los abonos siguen disponibles mientras exista saldo, incluso con el crédito bloqueado.
- El cliente bloqueado no puede seleccionarse para una venta a crédito.
- La API vuelve a validar el bloqueo al confirmar la venta, para impedir ventas a crédito desde cualquier cliente de escritorio.

## Datos y actualización

La migración `AgregaBloqueoDeCreditoCliente` incorpora `CreditFrozen` en los clientes con valor inicial `false`. Por tanto, la actualización no bloquea a ningún cliente existente.

## Prueba manual

1. Ve a `Créditos F2`, abre una cuenta con saldo y marca `Bloquear nuevas ventas a crédito`.
2. Guarda la cuenta y registra un abono: debe permitirse.
3. Intenta cobrar una venta a crédito para el mismo cliente: la selección debe avisar que el crédito está bloqueado.
4. Desmarca el bloqueo y guarda: el cliente debe quedar disponible de nuevo para crédito, respetando su límite.
