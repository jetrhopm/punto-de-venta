# JetVenta 2.3.4

## Alcance

Esta versión simplifica los dos accesos de credenciales. No modifica tickets, ventas, turnos, permisos almacenados, inventario ni la API de autenticación.

## Cambios

- El login carga las cuentas activas, selecciona la primera por defecto y permite cambiarla únicamente desde la lista.
- El usuario ya no necesita escribir ni puede alterar el nombre de una cuenta; sólo captura su contraseña.
- La autorización temporal muestra las mismas cuentas activas y deja la primera elegida por defecto.
- Se elimina el filtro manual de usuarios en la autorización para evitar confundirlo con una credencial obligatoria.

## Pruebas de regresión

1. Abrir JetVenta y comprobar que el primer usuario activo aparece elegido.
2. Elegir otra cuenta de la lista, escribir únicamente su contraseña y entrar.
3. Intentar entrar con contraseña incorrecta y confirmar que el mensaje no cambia la cuenta elegida.
4. Abrir una acción restringida y comprobar que la autorización temporal lista las cuentas, selecciona una y sólo pide contraseña.
5. Aprobar con una cuenta válida y luego crear un ticket, agregar un producto y cobrar una venta de prueba.

## Criterios de aceptación

- Ningún login exige escribir el nombre de usuario.
- Las listas sólo contienen usuarios activos.
- La cuenta seleccionada es la que se envía a la API junto con su contraseña.
- Los rechazos por contraseña o falta de permiso siguen mostrando el motivo específico.
