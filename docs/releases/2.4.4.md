# JetVenta 2.4.4

## Protección de cantidad temporal
- El flujo de código no encontrado conserva localmente la identidad del producto común temporal creado para el ticket.
- Aunque se reciba una respuesta anterior sin el indicador temporal o se procese un evento adicional, ese artículo no puede abrir `Cantidad de la partida`.
- La captura de cantidad por peso permanece exclusiva para productos existentes de inventario.
