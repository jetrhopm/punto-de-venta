# JetVenta 3.0.1 - Estabilidad de planificación de compras

- La carga inicial de listas, filtros y órdenes reintenta automáticamente mientras la API termina de iniciar o aplicar migraciones.
- Los mensajes diferencian una API en preparación de una indisponibilidad persistente.
- No modifica el cálculo de sugerencias ni el flujo de órdenes; no altera inventario, costos, precios ni ventas.
