# JetVenta 2.7.3 - Diagnóstico de documentos de impresión

## Mejora

Diagnóstico ahora explica y resuelve por separado los documentos de impresión:

- **Cola pendiente:** muestra que las ventas ya están confirmadas y permite descartar sólo los intentos de impresión cuando ya no se necesitan.
- **Historial técnico:** permite limpiar comprobantes ya generados o impresos.
- Ambas acciones usan confirmación visual de JetVenta y aclaran que no eliminan ventas, tickets, pagos, inventario, turnos ni cortes.

- Base anterior: `v2.7.2`.
- Se mantienen los tags desde `v2.5.5` hasta `v2.7.2`.
