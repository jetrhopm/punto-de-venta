# JetVenta 2.3.11

## Impresión de tickets
- Configuración > Impresora incorpora **Usar impresora para tickets**.
- Sólo cuando esta opción está activada y existe una impresora seleccionada se muestra **Cobrar e imprimir**.
- Si se desactiva, la venta confirma sin imprimir y no abre el guardado de PDF. La impresora seleccionada se conserva para reactivarla después.

## Compras y lector de código
- El buscador de Compras acepta flechas para elegir coincidencias y Enter para agregar una coincidencia única o código exacto.
- El lector USB configurado como teclado funciona al enviar Enter; el lector serial también se atiende mientras Compras está abierto.
- Al recibir una compra se captura cantidad, costo unitario y nuevo precio de venta. JetVenta actualiza el margen calculado y muestra una confirmación visible.

## Producto común temporal
- Desde Producto no encontrado, **Producto común (temporal)** es el botón predeterminado azul. Enter usa esta acción.
- El producto temporal se agrega desde ese mismo diálogo y no abre el formulario de Ctrl+P.
- El código es opcional para el temporal; registrar el producto permanente sigue requiriendo código.
- Ctrl+P mantiene su formulario propio y deja vacíos precio unitario y cantidad para captura con teclado.

## Pruebas manuales
1. En Configuración > Impresora, desactiva el uso de impresora, cobra una venta y confirma que sólo aparece **Cobrar F1**, sin impresión ni PDF. Reactívala con una impresora de Windows y confirma que vuelve **Cobrar e imprimir F1**.
2. En Compras, escribe o escanea un código existente y pulsa Enter. Confirma que selecciona el producto y coloca el cursor en cantidad. Modifica costo o precio y recibe la compra; revisa la alerta y el margen.
3. En Ventas, captura un código inexistente, completa descripción, precio y unidad, y pulsa Enter. Confirma que se agrega un artículo temporal sin abrir otra ventana ni modificar inventario.
4. Pulsa Ctrl+P y confirma que precio y cantidad inician vacíos.
