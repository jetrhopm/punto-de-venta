# JetVenta 2.3.7

## Alcance

Esta versión mejora la comunicación de configuración y el mantenimiento de la cola técnica de impresión. No modifica ventas, tickets, pagos, inventario, turnos ni la cola pendiente de impresión.

## Cambios

- Configuración de corte traduce las validaciones HTTP a mensajes claros para la persona usuaria.
- Al guardar Corte, moneda, unidad de medida, formas de pago, opciones de tienda, datos de tienda o diseño de ticket, JetVenta confirma el resultado y cierra el diálogo.
- La confirmación indica explícitamente que esos cambios se aplican sin reiniciar; cada mensaje aclara desde qué operación surtirá efecto.
- Diagnóstico separa los trabajos que aún requieren atención de los documentos técnicos ya generados o impresos.
- Se agregó **Limpiar historial técnico**. Sólo elimina registros de impresión `Generated` o `Printed`; no elimina ventas, líneas de venta, tickets, inventario, pagos, turnos ni documentos aún pendientes.

## Pruebas de regresión

1. En Configuración > Corte, activar el límite de efectivo y dejarlo en `0.00`; al guardar debe decir que se requiere un importe mayor a cero, sin JSON.
2. Guardar una configuración válida de corte y confirmar el mensaje; al aceptarlo, la ventana debe cerrarse y el siguiente cierre debe conservar la regla.
3. Guardar moneda, unidad, formas de pago y diseño de ticket: cada diálogo debe confirmar y cerrarse sin pedir reiniciar.
4. En Diagnóstico, comprobar que trabajos pendientes no habilitan la limpieza.
5. Si existe historial técnico de impresión, usar Limpiar historial técnico y confirmar que las ventas y los tickets siguen disponibles.
