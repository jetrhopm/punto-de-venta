# JetVenta 3.3.37 - Mejora lector de barras en ajuste de inventario

## Corrección

- En **Inventario > Ajustar inventario**, el Enter del lector se bloquea inmediatamente.
- Al escanear un código exacto, JetVenta selecciona automáticamente el artículo y enfoca la cantidad.
- El Enter de la lectura no puede registrar por accidente un ajuste de inventario.
