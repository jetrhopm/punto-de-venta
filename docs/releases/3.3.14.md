# JetVenta 3.3.14 - Solicitudes de factura

## Implementado

- El módulo `Facturas` ahora registra solicitudes asociadas a ventas confirmadas.
- Una solicitud almacena RFC, nombre fiscal, correo opcional, notas, usuario y fecha.
- El historial es compartido por la tienda y se puede buscar por folio, RFC o receptor.
- Sólo se permite una solicitud por venta para evitar duplicidad durante la futura integración con PAC.

## Límites deliberados

- No genera CFDI, XML, PDF, sello, timbre ni factura fiscal.
- No altera ventas, precios, inventario, cobros ni tickets.
- El acceso requiere `Configurar tienda`; el permiso fiscal específico se definirá junto con el PAC.
