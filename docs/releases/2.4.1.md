# JetVenta 2.4.1

## Producto común desde código no encontrado
- El mismo diálogo ahora solicita descripción, precio, cantidad y unidad o granel.
- Precio inicia en `0.00` y cantidad en `1`.
- Al hacer clic o avanzar con Tab a precio o cantidad, JetVenta selecciona el contenido completo para capturarlo de inmediato con teclado o lector.
- Enter conserva Producto común (temporal) como acción predeterminada; agrega la cantidad indicada sin modificar inventario.

## Prueba
1. En Ventas captura un código inexistente.
2. Completa descripción, pulsa Tab hasta precio y cantidad, y confirma que cada campo selecciona todo su valor.
3. Elige Kilogramo o Gramo, ingresa una cantidad decimal y pulsa Enter.
4. Confirma que el ticket muestra la cantidad seleccionada y que no aparece otro formulario.
