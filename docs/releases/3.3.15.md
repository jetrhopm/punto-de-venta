# JetVenta 3.3.15 - PAC propio por tienda

## Implementado

- Configuración autoservicio de **Facturama API Web** para la tienda emisora.
- Sandbox y Producción son ambientes separados; la tienda crea y contrata directamente su propia cuenta y timbres.
- Accesos directos de registro para Sandbox y Producción desde JetVenta.
- Prueba de conexión que verifica las credenciales contra Facturama antes de cualquier timbrado futuro.
- El correo y la contraseña API se guardan únicamente en el servidor local, cifrados con Windows DPAPI. Las cajas adicionales no muestran ni envían estas credenciales.

## Límites deliberados

- Esta versión no timbra CFDI ni genera XML/PDF fiscales.
- Las solicitudes de factura, ventas, inventario, pagos y tickets no cambian.
- Antes de timbrar se requiere completar la configuración fiscal de productos, impuestos y catálogos SAT; no se emitirán CFDI con datos inventados.
