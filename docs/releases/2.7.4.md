# JetVenta 2.7.4 - Diseño de clientes y créditos

Se renovó únicamente la presentación de Clientes y Créditos:

- Encabezados, buscador, resumen de saldo y lista con jerarquía visual más clara.

- Se conservaron los flujos, permisos, operaciones, consultas, dobles clics y acciones existentes.
