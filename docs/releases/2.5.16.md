# JetVenta 2.5.16

## Alcance

Corrección puntual del flujo de importación identificado en las pruebas. No modifica ventas, compras, inventario manual, productos existentes ni reglas de importación.

## Departamento disponible en F4

- Al cerrar la ventana de importación abierta desde Inventario F4, JetVenta recarga la lista de departamentos y el catálogo de inventario.
- Los departamentos nuevos creados por el archivo quedan disponibles inmediatamente para asignar o filtrar productos, sin salir y volver a entrar a Inventario.

## Existencias y filas omitidas

- La versión 2.5.14 conserva la existencia final indicada por el archivo, incluso con el control global de inventario deshabilitado.
- Las filas desmarcadas se omiten una por una: no se envían a la API, no se validan y no impiden importar las demás filas seleccionadas.
- Las filas seleccionadas se validan como un lote atómico. Si una seleccionada contiene un error, no se guarda parte del lote; el usuario puede corregirla o desmarcar sólo esa fila.

## Mensaje de confirmación

La actualización de productos explica que la existencia siempre se toma del archivo y que el movimiento de inventario se registra cuando el control de inventario está habilitado.

## Punto de retorno

La versión se etiquetará como `v2.5.16` después de compilar y ejecutar pruebas. Las etiquetas `v2.5.5` a `v2.5.15` se conservan sin cambios.
