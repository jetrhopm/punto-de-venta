# JetVenta 3.3.22

## Respaldos `.bjv`

- La copia externa se guarda ahora como un único archivo `.bjv`.
- El archivo contiene el respaldo PostgreSQL y su comprobación SHA-256; JetVenta verifica ambos antes de iniciar una restauración.
- La restauración conserva compatibilidad con copias anteriores `.dump` junto con su archivo `.sha256`.
- El instalador registra el icono azul de respaldo aprobado para archivos `.bjv` en Windows.

## Validación

1. Crear un respaldo desde Configuración > Respaldos.
2. Guardar una copia externa y verificar que se genere un único archivo `.bjv` con su icono.
3. Cargar esa copia y confirmar que JetVenta la verifica antes de solicitar la restauración.
4. Confirmar que un respaldo histórico `.dump` con su `.sha256` continúa siendo aceptado.
