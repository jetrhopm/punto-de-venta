# JetVenta 4.0.0 - Integraciones: conciliación Mercado Pago Point

## Implementado

- Recepción segura de Webhooks de órdenes Point con HMAC SHA-256,
  comparación de tiempo constante y expiración de notificaciones antiguas.
- Cola persistente e idempotente de eventos; una notificación repetida no
  duplica ninguna orden ni cobro.
- Servicio de conciliación que toma la orden de Mercado Pago como fuente de
  verdad antes de actualizar su estado local.
- Estado visible de Webhook pendiente dentro de Configuración > Mercado Pago
  Point, separado de la conexión de cuenta y de la terminal de caja.

## Requisitos antes de usarlo

Se necesita una aplicación Point, credenciales de sandbox, `WebhookSecret` y
una URL HTTPS pública. Esos secretos no se guardan en JetVenta, en la base de
datos ni en Git.

## No modificado

Ventas, tickets, inventario, caja, permisos, multicaja y Taecel/La Red+ no se
alteran en este incremento.
