# JetVenta 2.5.31 - Búsqueda asíncrona de promociones

## Cambio

La ventana de Promociones incorpora un buscador sobre el listado. Filtra promociones activas o bajas visibles por nombre de promoción, código de producto y descripción del producto.

La búsqueda espera brevemente después de escribir y cancela la consulta anterior, evitando bloqueos o resultados fuera de orden cuando se escribe rápido.

## Prueba manual

1. Abre Productos F3 > Promociones.
2. Escribe parte del nombre de una promoción, código o descripción de producto en el buscador sobre la tabla.
3. Confirma que la lista se actualiza sin presionar un botón y que muestra sólo coincidencias.
4. Borra el texto y confirma que reaparecen las promociones según el filtro de bajas activo.
