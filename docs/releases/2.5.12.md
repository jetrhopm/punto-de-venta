# JetVenta 2.5.12 - Tiempo operativo, API y comprobante de corte

## Alcance

- Conserva UTC como formato de almacenamiento y toma `TimeZoneInfo.Local` de Windows para los rangos de corte por fecha. No modifica marcas de tiempo históricas ni el formato de respaldos.
- Agrega una vigilancia ligera de `health` mientras la ventana principal está abierta. Un aviso rojo indica pérdida de API y dirige a Configuración > Diagnóstico > Levantar API. Un aviso azul único confirma la recuperación.
- El límite de efectivo sigue calculando sólo fondo inicial, ventas en efectivo, entradas y salidas de efectivo. La configuración permite advertir o bloquear nuevos cobros en efectivo hasta que se registre un retiro autorizado. Tarjeta, transferencia y crédito quedan fuera del límite.
- El cierre de turno consulta el desglose actual y, después de que la API confirma el cierre, imprime fondo inicial, ventas por forma de pago, entradas, salidas, devoluciones, efectivo esperado, contado y diferencia. Si la impresión está desactivada o no hay impresora, el cierre no se bloquea y se informa el motivo.

## Migración

`20260909090713_AgregaBloqueoPorLimiteDeEfectivo` agrega el indicador persistente del modo de bloqueo. Las tiendas actualizadas conservan el modo de advertencia como valor predeterminado.

## Regresión obligatoria

1. Configurar Windows en la zona horaria local real, crear movimientos cercanos a medianoche y comprobar el corte por fecha.
2. Detener la API con JetVenta abierto, comprobar el aviso rojo; levantarla desde Diagnóstico y comprobar el aviso azul.
3. Con límite activo, registrar tarjeta, transferencia y crédito; confirmar que no bloquean por efectivo. Probar efectivo en modo aviso y en modo bloqueo.
4. Cerrar un turno con impresora activa y validar el comprobante. Repetir sin impresora configurada y confirmar que el turno sí cierra.
5. Crear respaldo, limpiar datos y restaurar; validar un corte y un reporte por fecha en el equipo restaurado.
