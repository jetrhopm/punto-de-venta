# JetVenta 3.3.38 - Mejora lector de barras en ajuste de inventario

## Corrección

- La búsqueda asíncrona de **Ajustar inventario** ahora aplica `SelectProduct` automáticamente si el código ingresado coincide exactamente.
- El comportamiento es idéntico al doble clic manual: oculta resultados, muestra el artículo seleccionado y enfoca la cantidad.
- No depende del evento Enter del lector para seleccionar el producto.
