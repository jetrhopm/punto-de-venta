# JetVenta 3.5.0.13 - Paquete de pruebas y recuperación

Esta versión reúne los cambios acumulados hasta el 11 de octubre de 2026. Es una compilación de pruebas; la publicación de este checkpoint no sustituye las pruebas de instalación limpia ni las pruebas reales de terminal.

## Mercado Pago Point

- La API carga `appsettings.json` desde la carpeta de sus ensamblados cuando se inicia como servicio o desde otro directorio. Esto corrige el caso de desarrollo en que JetVenta iniciaba la API desde la raíz del proyecto y el broker HTTPS (`MercadoPago:BrokerUrl`) quedaba sin cargar.
- La ventana de configuración ya no permite autorizar a ciegas si no logra consultar primero el estado de la conexión; muestra una indicación para reiniciar/reabrir y deja visible el error de diagnóstico.
- El mensaje de configuración faltante orienta a actualizar JetVenta en la caja principal.
- El broker configurado es `https://mp.gocentersuplementos.com.mx/`. No se incluyen tokens, secretos OAuth ni credenciales de clientes en el repositorio.

### Protecciones Point incorporadas previamente

Los cambios de seguridad y recuperación Point de las versiones 3.3.46–3.3.53 y 3.4.0.0 permanecen incluidos en la historia del proyecto:

- La venta con tarjeta requiere una orden Point aprobada para la caja configurada, con importe verificado; se evita registrar una venta como pagada cuando el cajero no puede consultar configuración.
- Cada intento tiene identidad/idempotencia propia; una orden incierta se conserva y reconcilia con el mismo ticket e importe, en vez de crear un segundo cargo tras timeout o cierre inesperado.
- Rechazos, cancelaciones y estados pendientes tienen rutas de reintento/control; la ventana interpreta respuestas JSON de error y presenta validaciones en español.
- Cancelar o devolver una venta Point solicita reembolso antes de alterar inventario, efectivo o estado local. Se registran reembolsos para consulta/reintento; las devoluciones desde otra caja buscan la orden de la caja original de la venta.
- No se declara un reembolso/cancelación como exitoso sin confirmación del proveedor. Los casos no conciliables permanecen bloqueados para revisión, sin simular que el dinero regresó.
- OAuth/webhook central y habilitación de producción siguen dependiendo de la infraestructura pública del broker y deben probarse con la cuenta del cliente antes de operar.

El detalle y los límites de cada cambio están en `docs/releases/3.3.46.md` a `docs/releases/3.3.53.md` y `docs/releases/3.4.0.0.md`.

## Otras mejoras agrupadas

- JetVenta Móvil incorpora menú de verificador, conteo de inventario con historial/diferencias, lista local de compras y solicitudes de recepción a proveedores que escritorio aprueba o rechaza. Se conserva la cámara compartida y la cámara trasera predeterminada.
- Licencias distinguen Desktop y Desktop + Móvil; el instalador puede importar/actualizar una licencia y la API valida el acceso móvil.
- Google Drive agrega respaldo/restauración cifrable iniciado por el dueño de la cuenta, retención, reintento y recuperación tras cierre forzado. Requiere configurar credenciales OAuth propias; no se incluyeron en esta entrega.
- Escritorio incorpora revisión de solicitudes de compra móvil, opciones de pagos a proveedores, mejoras de movimientos de inventario y ajustes de conexión/licencia.
