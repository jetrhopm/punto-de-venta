# JetVenta 3.3.26 - Instalación inicial confiable

## Correcciones

- La creación de tienda, administrador y primera caja ya no queda bloqueada por un problema al completar departamentos predeterminados heredados de una migración.
- Los departamentos se completan después de confirmar la creación principal. Si alguno ya existe o presenta un conflicto técnico, la tienda queda lista y el catálogo los normaliza al abrir Productos.
- Antes de iniciar la API, el instalador detiene procesos residuales de JetVenta que pudieron quedar de una reparación anterior.
- El instalador confirma que el puerto `5000` lo atiende el servicio recién instalado. Si otro proceso lo ocupa, detiene la instalación con un diagnóstico claro en lugar de abrir el cliente contra una API anterior.

## Prueba de instalación limpia

1. Instalar como `Caja principal / servidor`.
2. Esperar el mensaje de instalación terminada.
3. Abrir JetVenta y completar nombre de tienda, giro, administrador y nombre de caja.
4. Confirmar que se llega al inicio de sesión y que Productos muestra los departamentos predeterminados.
