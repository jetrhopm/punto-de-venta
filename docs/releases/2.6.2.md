# JetVenta 2.6.2 - Producto común por granel

## Cambio

La ventana de producto común abierta con `Ctrl+P` ahora inicia con `Kilogramo (granel)` como unidad de venta predeterminada. El usuario puede elegir cualquier otra unidad antes de agregar el artículo temporal al ticket.

## Retorno seguro

- Base anterior: `v2.6.1`.
- Se conservan todos los tags desde `v2.5.5` hasta `v2.6.1`.
