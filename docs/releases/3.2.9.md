# JetVenta 3.2.9 - Cierre de configuraciones de cajón y báscula

Al guardar correctamente la configuración de `Cajón de dinero` o `Báscula`, el cuadro de resultado se muestra con el diseño global y, al pulsar `Aceptar`, se cierra también la ventana de configuración.

Las pruebas de dispositivo, validaciones y errores continúan dejando la ventana abierta para que el usuario pueda corregir la configuración o repetir la prueba.
