# JetVenta 3.3.33 - Mejora lector de barras en kits

## Corrección

- En **Buscar artículo para agregar** de Kits, el Enter del lector USB ya no activa guardar ni otra acción de la ventana.
- Si el código leído coincide exactamente con un artículo, JetVenta lo selecciona automáticamente como componente del kit.
- Las coincidencias parciales continúan mostrándose en la lista para elección manual.
