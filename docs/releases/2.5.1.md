# JetVenta 2.5.1

## Cambios

- F3 deja la lista como vista principal y oculta el editor lateral.
- `Nuevo producto` abre un diálogo dedicado para el alta.
- `Editar seleccionado` y el doble clic sobre una fila abren el mismo diálogo con todos los datos cargados.
- En edición se envía `PUT` usando el identificador del producto seleccionado; nunca se crea un producto nuevo. La existencia actual se muestra, pero los cambios de existencia siguen pasando por Inventario/Ajustar para conservar el historial.
- El diálogo acepta `Enter` para guardar y `Esc` para cancelar.
- F4 permite escanear o escribir un código y presionar `Enter`. Se selecciona primero la coincidencia cuyo código completo coincide; por ejemplo, `100` selecciona `100` aunque también existan `1000` y `A100`.
- Después de seleccionar el producto por código, el foco pasa a la cantidad y selecciona su contenido para continuar sin mouse.

## Verificación

- `dotnet build .\\PuntoDeVenta.slnx -c Debug --no-restore`
- `dotnet test .\\PuntoDeVenta.slnx -c Debug --no-restore`
- Resultado: 29 unitarias, 18 de escritorio y 16 de integración superadas.

## Pruebas manuales

1. Entrar a F3 y confirmar que sólo aparece la lista.
2. Pulsar `Nuevo producto`, guardar y confirmar que aparece en la lista.
3. Seleccionar un producto, usar doble clic, modificar descripción o precio y confirmar que se actualizó el mismo código sin duplicarlo.
4. En F4 escanear `100` y pulsar `Enter`; confirmar que se selecciona el código exacto y que el foco queda en cantidad.
