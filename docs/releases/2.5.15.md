# JetVenta 2.5.15

## Alcance

Corrección puntual de permisos registrada en la revisión 2.5.5 a 2.5.13. No cambia permisos permanentes, ventas, inventario ni producto común temporal.

## Autorización temporal en catálogo

- Crear o editar un producto solicita autorización temporal `Administrar productos, promociones y kits` cuando la cuenta actual no la tiene.
- Crear, editar, desactivar o reactivar un departamento solicita la misma autorización antes de enviar la operación a la API.
- La autorización sólo cubre la acción solicitada. Se revoca al terminar, incluso si la operación falla.

## Mensajes de autorización

El diálogo existente muestra una alerta visible cuando:

- La contraseña no corresponde a la cuenta seleccionada.
- La cuenta seleccionada no tiene el permiso requerido.
- No se eligió cuenta, no se capturó contraseña o no se puede contactar la API.

## Pruebas de regresión

- Se agregó una prueba de integración: un cajero no puede crear un producto sin permiso, puede hacerlo tras la autorización temporal de un administrador y vuelve a quedar bloqueado cuando esa autorización se revoca.

## Punto de retorno

La versión se etiquetará como `v2.5.15` tras compilar y ejecutar las pruebas. Las etiquetas `v2.5.5` a `v2.5.14` se conservan sin cambios.
