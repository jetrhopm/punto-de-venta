# Contribuir

## Flujo de trabajo

1. Mantener `main` compilando.
2. Trabajar cambios por ramas cortas.
3. Usar commits pequenos con mensajes descriptivos en espanol.
4. Ejecutar pruebas antes de subir cambios.
5. Documentar decisiones importantes en `DECISIONS.md`.

## Mensajes de commit

Usa texto real y claro:

```text
Documenta requisitos de desarrollo
Crea estructura inicial de la solucion
Agrega iconos iniciales del punto de venta
Implementa cobro en efectivo con idempotencia
```

Evita:

```text
update
cambios
fase 1
123
```
